# 共享范围与校验

## 首次同步范围

逐项审查了原课程项目目录的 180 份文件。140 份原文件有仓库副本，40 份只在原工作目录保留。仓库还包含本阶段的说明、校验和指标复算工具。 [原文件处置清单](file_inventory.csv) · [Git 待跟踪准确清单](git_file_list.txt)

| 文件类型 | 处置依据 |
| --- | --- |
| 训练、评估和模型定义 | 25 份 Phase 1–6 Python 文件逐字节复制。各阶段保持相邻目录布局，固定训练和验证 ID 划分也逐字节复制。 |
| 历史结果 | 保留训练日志、配置、数值训练与 PR 曲线、阈值和面积分组、Bootstrap 及逐图 TP/FP/FN 等。逐图表使用课程样本编号和数值统计，支持校验固定划分及复算。 |
| Notebook | 共享目录包含 7 份清理执行输出的源 Notebook。原版基线训练及 Phase 5 报告含原图或掩码预览。Phase 5 共享报告只加载数值曲线，以便在没有预览图片的 clone 中运行。 |
| 数据、图像和缓存 | 约 15.17 GB 的课程 ZIP、图像像素与标签缓存、原始测试图、裁块和预测预览均留在本地。逐裁块坐标明细和中间数组可由缓存流程再生。 |
| 权重、重复包与生成物 | 检查点及独立提交 ZIP 留在本地。Phase 6 已执行 Notebook 和公测 RLE CSV 为本地验证记录。保留候选所依赖的少量重复模型文件、划分、训练表，以支持独立运行。 |
| 课程访问资料 | 课件含课程发放链接和访问参数，课程截图及原始模板也留在本地。共享报告移除私有邀请 URL，并保留原课程来源名称。 |
| 身份与路径 | Phase 6 原始验证 JSON 含本机解释器绝对路径，因此移出共享副本。成员身份需要填入正式 Canvas Notebook，仅保留组名与成员占位。新增基本运行记录使用环境名和相对路径。 |

对 Git 待跟踪文件做了常见 API Token、Kaggle 凭据、密码字段、私钥、邮箱、个人绝对路径、私有分享链接和 Notebook 执行输出扫描。文件类型及 ignore 规则也按实际 Git 结果核对。扫描面限定在拟共享的课程项目文件。 [扫描记录](git_audit.json) · [本地基本运行结果](smoke_test.json)

## 远程同步条件

公开仓库的首次同步范围以 [Git 清单](git_file_list.txt) 为准，由仓库所有者为组员授予写入权限。校验用的课程数据和权重继续从课程允许的渠道交接。Kaggle 的官方评分、上传格式和资源许可仍为 **UNVERIFIED**。
