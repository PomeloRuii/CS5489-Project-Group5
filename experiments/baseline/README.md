已在 [cs5489 环境](python_environment.txt) 用正式数据跑完 10 轮训练。数据包有 5,000 张带 RLE 标注的训练图和 500 张无标注公测图。固定从前者划出 500 张做验证，并保存了 [划分清单](split.json)。

最佳权重为 model.pth（本地留存）。[每轮训练记录](training_history.csv)、[训练曲线](training_curves.png)、[指标汇总](baseline_metrics.json)、[逐图验证结果](validation_by_image.csv) 和 预测对照图（本地留存） 已保存。微平均 IoU 先把 500 张图的交集像素和并集像素分别求和，再取比值。原图预测使用统一的 0.5 阈值，这些指标仅用于本地验证比较。

本版的前景召回率较低。500 张验证图中有 68 张预测全空，有 191 张预测与标注没有交集（含全空预测）。全前景预测的微平均 IoU 已有 13.07%，说明本版虽能定位个别图里的目标，整体效果仍接近简单参照。对照图里的飞机样本 002853 全部漏检，伞样本 003071 的掩码则与标注大致吻合。

## 开始训练

1. 用 VS Code 打开本目录，在 Notebook 中选择 Anaconda 的 cs5489 内核。运行时工作目录应为本目录，确保能导入同目录的 project.py 和 prepare_data.py。
2. 打开 [train.ipynb](train.ipynb)，核对首个代码单元中的压缩包路径。Notebook 直接从 ZIP 读取 WebP 和 train.csv，首次运行验证标注并创建 cache256。后续训练可直接复用缓存，交接时可用原压缩包重建。
3. 查看 掩码叠加图（本地留存） 和 结构核对记录（本地留存）。训练表的字段为 ID、annotation、height、width。RLE 按列扫描，从 1 编号。图片用双线性缩放，二值掩码用最近邻缩放。
4. 基线使用 256×256 输入、轻量 U-Net、Adam、BCE 与 Dice 损失，随机种子 5489，批大小 8，学习率 0.001。每轮验证一次，按缩放后验证掩码的前景微平均 IoU 选择 model.pth。
5. 打开 [test.ipynb](test.ipynb)，填入 Canvas 组名、成员、解压后的测试图目录和权重路径。推理恢复原图分辨率再二值化，并沿用课程模板的 RLE 编码器。已经用三张公测图验证真实权重加载、原图尺寸、编码往返和 ID 前导零。
